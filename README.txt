SNIGDHA'S 17TH BIRTHDAY WEBSITE

Files:
- index.html: complete responsive birthday website
- images/snigdha.jpg: the photo supplied for the website
- audio/: place your permitted MP3 file here later

Birthday countdown is set to 20 October 2026, India time (UTC+05:30).
The current music button plays a small generated melody. When you send your MP3, this can be replaced with your chosen song.

To publish on GitHub Pages, upload/replace index.html and the images folder in the repository. Keep images/snigdha.jpg in the same path.
